# 方案：公平地比较 MOGP 和线性回归

## 1. 这次要回答什么

> **在掌握同样信息的情况下，MOGP 预测 Cd 是否比线性回归更准？给出的"误差范围"是否更可信？**

可以把它想成**几个学生考同一场试**。

- 线性回归：只用"这个点的 Ni、Zn 是多少"来算 Cd
- MOGP：除了 Ni、Zn，还会参考"附近的点 Cd 是多少"

所以，这次实际要检验的是：**"参考邻居"到底有没有用？**

## 2. 上次哪里不公平

| 问题 | 上次的做法 | 这次的做法 |
|---|---|---|
| 考的次数不一样 | MOGP 考了 10 次，回归只考 1 次 | 两者考同样的 10 次 |
| 没有检验 | "GP 多贡献 4%"没有做显著性检验 | 做配对检验 |
| 头条数字比错了对象 | "+26%"比的是一个不看 Ni/Zn 的模型 | 主要对手换成同样知道位置的回归 |
| 优点只说不测 | 声称"回归给不出不确定度"（其实能给） | 两者都给出 95% 区间，实际比较 |

## 3. 参赛者

| 模型 | 公式 / 设置 | 用到的信息 |
|---|---|---|
| **回归 A（普通）** | `Cd = a + b·Ni + c·Zn` | 这个点的 Ni、Zn |
| **回归 B（加位置）** | `Cd = a + b·Ni + c·Zn + d·X + e·Y + f·X² + g·Y² + h·X·Y` | 这个点的 Ni、Zn，以及大范围的趋势（整体倾斜，外加一个大的弯曲） |
| **回归 C（再加岩石、土地用途）** | 回归 B，再加上岩石类型和土地用途 | 回归 B 的全部信息，再加上这个点的岩石类型、土地用途 |
| **MOGP** | 第一次汇报里选定的 LMC（Q=2），设置不变 | 这个点的 Ni、Zn，以及身边具体邻居的情况 |

打个比方：回归 B 知道"你住在城市东区"，MOGP 知道"你隔壁邻居家是什么情况"。

### 为什么回归 B 要加平方项
- 只用 X、Y 时，回归只能表示"一边高一边低"的整体倾斜，像一块斜放的木板。
- 加上 X²、Y²、X·Y 后，它还能表示"中间高、四周低"这类形状，像一张可以弯一次的纸。
- 这**仍然是线性回归**："线性"指的是公式由"系数 × 某一列数据"相加而成，X² 只是多加的一列数据。
- 这样做是为了公平：让对手尽量强一点。如果连能弯的纸都输了，MOGP 赢得更有说服力。

### 主比较和附加比较
- **主比较：回归 B 对 MOGP。**两者用到的信息最接近（Ni、Zn、位置），是公平的对决。
- **附加比较：回归 C 对 MOGP。**回归 C 比 MOGP **多知道**岩石类型和土地用途，所以不算公平对决，相当于让回归多带了一本参考书。它回答的是一个实际问题：**岩石、土地用途这类便宜的分类信息，能不能让简单方法追上复杂方法？**汇报里要明确说清楚这一点。

每一步比较各自回答一个问题：

- **A → B**：知道大范围的趋势，有没有用？
- **B → MOGP**：在都知道位置的前提下，参考身边的邻居还有没有额外的用处？
- **B → C**：岩石类型、土地用途有没有用？
- **C 对 MOGP**：多带一本参考书的简单方法，能不能追上复杂方法？

不管哪一种结果（比如 B 已经追平 MOGP，或者 C 超过了 MOGP），都是有价值的诚实结论。

### 岩石类型、土地用途怎么放进回归
- 它们是"类别"，不是数字。放进回归的方式是为每一类建一列"是 / 不是这一类"（1 或 0）。
- **每组要去掉一列作为"参照类"**：一个点总是恰好属于某一类，所以 5 列岩石加起来永远等于 1，和公式里的常数项 a 重复，系数就算不出唯一的答案。去掉的那一类，就是其它类比较的基准。
- **样本太少的类别**：全部 359 个点里，岩石第 4 类只有 6 个点，土地用途第 4 类只有 8 个点。点这么少，单独给它们估系数会很不准。**赛前规定：少于 10 个点的类别，并入该组里点最多的那一类**（岩石第 2 类，124 个点；土地用途第 3 类，218 个点），并在备用页说明。

## 4. 六条公平规则

**规则 1：同一张考卷。**
所有模型使用完全相同的 10 次随机划分，每次藏起同样的 100 个点。
→ 为什么：考卷有难有易，只考 1 次，可能刚好碰上一张难卷或者易卷。

**规则 2：同样的复习资料。**
所有模型都只能看训练集里的 259 个 Cd，测试点的 Cd 谁都不准偷看。取 log、标准化也只用训练数据来算，所有模型用同一套处理方式。
→ 为什么：如果有人偷看了答案，或者处理方式不一样，比出来的差距就不完全是模型本身的差距。

**规则 3：赛前把参赛方式定死。**
MOGP 的设置沿用第一次汇报定下的（Q=2、训练步数等），看到测试结果以后不再调。线性回归本身没有需要调的东西。
→ 为什么：看了成绩再回头调参数，就像考完试再改答案，会偏向被反复调的那一方。

**规则 4：同样的评分标准，比两项。**
- **准不准**：RMSE，也就是"平均错多少"，越小越好
- **误差范围可不可信**：每个模型都给出一个"95% 有把握的区间"，然后看 100 个真值里实际有多少落在区间里。理想情况是大约 95 个。

→ 为什么：线性回归有标准的预测区间公式，应用统计课本里就有。让所有模型都交出区间，用事实来比。

**规则 5：配对比较。**
每次划分都算一个"MOGP 比回归少错多少"，10 次就得到 10 个差值。看这 10 个差值整体上是不是明显大于 0（配对 t 检验），同时数一数 10 次里各赢几次。
→ 为什么：同一张考卷上的成绩直接相减，考卷难易的影响就抵消了，剩下的就是真正的实力差。

**规则 6：赛前写下"怎样才算赢"。**
跑之前先写好判定标准（见下一节），结果出来以后严格照着写结论。
→ 为什么：先定标准再看结果，就不会出现"挑对自己有利的说法"。这一条最直接地回应"偏袒 MOGP"的批评。

## 5. 判定标准（赛前定好，结果出来后不改）

- **准不准（主比较）**：MOGP 对回归 B 的 10 个差值，配对 t 检验 p < 0.05，并且平均差值大于 0，才说"MOGP 比回归更准"。否则写"两者准确度没有明显差别"。
- **误差范围**：哪个模型的实际覆盖率更接近 95%，哪个的误差范围就更可信。
- **附加比较**：MOGP 对回归 C 用同样的检验和同样的标准，但结论要注明"回归 C 多用了岩石和土地用途"。
- MOGP 对回归 A 的比较也同样报告，但只作为参考。
- **回归 B 用平方项**，这是赛前定好的。另外只用训练数据做一个 F 检验，看加了平方项以后拟合是不是明显变好；结果放在备用页，不管结果如何都不再改回归 B 的公式。

## 6. 解释"为什么"：残差地图

画一张研究区地图，每个点按"回归 B 预测错了多少"来上色：红色表示猜低了，蓝色表示猜高了。

- **红点扎堆、蓝点扎堆**：说明回归漏掉了"邻居"这条信息，而 MOGP 正好用到了它，可以解释 MOGP 为什么赢。
- **颜色混在一起、看不出规律**：说明邻居信息用处不大，MOGP 赢不了也讲得通。

## 7. 这次故意不做的事

- 不加入其它方法，只比这四个。
- 不改变划分方式，沿用随机划分。在汇报里说明一句：采样点有些挤在一起，随机划分可能让"参考邻居"的方法占一点便宜。
- 不给 MOGP 加岩石类型和土地用途（见 [待讨论.md](待讨论.md)）。
- 不讲第一次汇报里的两个空间尺度、BIC 选 Q 等内容，和这次的问题无关。
