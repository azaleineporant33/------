# 1. `jura_eda.png` — 出自 [01_load_jura](src/01_load_jura)

**三行布局：**

- **第一行（3张空间散点图）**：log(Cd)、log(Ni)、log(Zn) 分别在研究区里的空间分布，颜色深浅代表浓度高低。作用是让人一眼看到"哪里高哪里低"，也初步感觉三张图的高值区大致重叠。
- **第二行（6个直方图）**：每个金属的"原始浓度"和"log 变换后"对比，标了偏度（skew）。Cd 和 Zn 原始右偏严重（+1.48、+1.49），log 后接近对称。**Ni 那张标红并注明"worse"**——它原始就接近对称（+0.11），log 后反而变左偏（−1.13），这是刻意保留的诚实呈现，不是所有金属都该无脑取 log。
- **第三行（相关性热图）**：Cd/Ni/Zn 两两的 Pearson 相关系数——0.654 / 0.686 / 0.699。这是整个项目的立论基础：**三个金属确实相关，所以借力预测才可能有效。**

## 5. `stage10_robustness.png` — 出自 [07_robustness.py](src/07_robustness.py)

**三个面板，都是关于"结果是不是运气"：**

- **左**：10 次随机划分（种子 0-9），每次的独立GP/ICM/LMC 三色柱状对比，横线标出"常数预测器"基准（RMSE=1.0）。
- **中**：同样三组数据的箱线图，能看出 GP 那组明显偏高且分散，ICM/LMC 两组低且重叠严重。
- **右**：**配对折线图**（spaghetti plot）——每条灰线代表一次划分，连接 GP→ICM→LMC 三点。GP→ICM 那一段线条几乎全部同向下降且陡峭（标注 10/10 显著，p=2.6e-07），ICM→LMC 那一段线条方向凌乱、有升有降（标注 5/10、p=0.19，不显著）。**这张图是"LMC 不比 ICM 预测得更好"这个结论最直观的证据。**

## 6. `stage9_latent_decomposition.png` — 出自 [06_spatial_maps.py](src/06_spatial_maps.py)

**三个空间热力图：**

- **左**：短程潜在函数 q=1 对预测均值的贡献，空间上是一堆孤立的小色块，紧贴在训练点附近——局部效应。

## 7. `stage9_spatial_maps.png` — 出自 [06_spatial_maps.py](src/06_spatial_maps.py)（最大的一张图，6个面板）

**上排（预测均值）**：独立GP的均值图 / LMC的均值图 / 两者之差。能看出独立GP画出来的浓度分布比较模糊平滑，LMC的更贴近局部细节，且和真实观测点（白圈=训练、红三角=测试）位置对应更好。

**下排（不确定性）**：独立GP的标准差图 / LMC的标准差图 / 不确定性下降百分比（红=LMC更确定，蓝=LMC反而更不确定）。**最后这张图是全项目最重要的证据之一**：红色区域集中在采样点附近，蓝色区域是采样点之间——证明"借力"是有空间范围限制的，不是处处生效。

## 8. `stage9_uncertainty_vs_distance.png` — 出自 [06_spatial_maps.py](src/06_spatial_maps.py)

**两个面板，是上一张图右下角那个发现的定量版：**

## 9. `transect_prediction.png` — 出自 [11_transect_plot.py](src/11_transect_plot.py)

这是最新加的一张，也是**唯一一张"经典GP教科书式"的图**（一维曲线+置信带，而不是二维热力图）：

沿着穿过 17 个采样位置的一条直线，画出独立GP（红）和MOGP/LMC（蓝）各自的预测曲线和95%置信带。图上还叠了实际观测点（白圈=Cd训练、空心三角=Cd测试），底部小竖线标出"这里有Ni/Zn观测"的位置，并且用红色竖虚线特别标出了两个"Cd从未测过、但MOGP的置信带依然收窄"的位置——因为那里虽然没测Cd，但同一坐标测了Ni/Zn，MOGP能借上这个信息，独立GP不能。

**这张图是最容易讲给非技术背景的人听的一张**：不需要任何术语，看一眼就知道"这个模型不仅给出预测，还知道自己在哪有把握、在哪没把握"。

## 一个需要你注意的重复

**`true_lmc.png` 和 `model_selection.png` 内容高度重叠**——两者都在讲"BIC/AIC选Q=2"和"潜在函数分解"，只是来源脚本不同（一个是notebook里的探索过程，一个是专门为报告做的干净版本）。汇报时**建议只选 `model_selection.png`**，它的柱状图（边际收益vs边际代价）比 `true_lmc.png` 的方差占比柱状图更直接地回答"为什么选2"，配色和标注也更规范。`true_lmc.png` 留着当notebook里的过程记录就行，不用重复放进汇报。
